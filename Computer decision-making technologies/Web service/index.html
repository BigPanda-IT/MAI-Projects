🎯 Метод агрегирования предпочтений

Система анализа экспертных оценок для принятия оптимальных решений

📚 Теоретические основы метода

Метод агрегирования предпочтений — это современный подход к принятию решений в условиях многокритериальности и нечеткости экспертных оценок.

📊 Работа с разнородными шкалами

Возможность сравнения критериев в разных единицах измерения без приведения к общей шкале

⚖️ Относительные оценки

Учет степени превосходства одной альтернативы над другой, а не абсолютных значений

🔍 Учет экспертных весов

Возможность задания коэффициентов важности критериев и компетентности экспертов

🎯 Непротиворечивость

Построение согласованных агрегированных предпочтений на основе индивидуальных оценок

pijt = xjt / (xit + xjt) — для критериев максимизации
pijt = xit / (xit + xjt) — для критериев минимизации

🔄 Алгоритм работы системы

1

Ввод исходных данных

Определение альтернатив, критериев и их характеристик

2

Построение матриц сравнений

Создание матриц парных сравнений для каждого критерия

3

Расчет суммарной матрицы

Агрегирование предпочтений по всем критериям

4

Построение графа предпочтений

Создание мажоритарного графа и матрицы весов

5

Ранжирование альтернатив

Вычисление индексов вершин и упорядочивание вариантов

6

Диалог с ЛПР

Обсуждение результатов с лицом, принимающим решение

7

Принятие окончательного решения

Выбор оптимальной альтернативы и визуализация результатов
